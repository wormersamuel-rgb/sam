# Tarifas medassure dental y adipo (España)

Comprobadas el 2026-10-06 con la calculadora de **medassurance.de** (servicios `settings` y `calculate`,
productos `jhc-medassure-dental-es` y `jhc-medassure-adipo-es`), igual que en `extraer_tarifas.py` para beauty.

## medassure dental: coincide con el formulario

| Categoría · coste del tratamiento | Básica 1 / 2 / 5 años | Premium 1 / 2 / 5 años |
|---|---|---|
| A · hasta 1.000 € | 99 / 128 / 215 € | 149 / 193 / 324 € |
| B · 1.001 a 1.500 € | 134 / 173 / 290 € | 201 / 260 / 436 € |
| C · 1.501 a 3.000 € | 169 / 218 / 365 € | 254 / 328 / 550 € |
| D · 3.001 a 5.000 € | 214 / 283 / 490 € | 321 / 425 / 737 € |
| E · más de 5.000 € | 259 / 348 / 615 € | 389 / 523 / 925 € |

- Periodontitis, diabetes o fumador/a: prima × 1,5. Se aplica **una sola vez** aunque haya varios factores
  (p. ej. C, Premium, 1 año con diabetes y tabaco = 381,00 €; C, Básica, 5 años con un factor = 547,50 €).
- La web solo vende dental con tratamiento en España; edad de 19 a 99 años.

## medassure adipo

Bypass y manga gástrica (cobertura fija; la web la llama «28 Tage», el formulario «29 días»):

| IMC | Básica | Premium |
|---|---:|---:|
| A · hasta 40 | 499 € | 599 € |
| B · más de 40 hasta 60 | 899 € | 999 € |

Coincide con la web. El IMC exactamente 40 cuenta como A; por encima de 60 no es asegurable.

**Procedimientos endoscópicos: no coinciden.** En la web de España, adipo solo tiene bypass y manga; el balón
gástrico y Endomina / POSE / Overstitch se contratan dentro de **medassure beauty**, con otros precios:

| | Formulario adipo (Básica / Premium) | Web, medassure beauty (Básica / Premium) |
|---|---|---|
| Endomina · POSE · Overstitch, 1 año | 289 / 399 € | 289 / **429** € |
| Endomina · POSE · Overstitch, 2 años | 399 / 549 € | **429 / 599** € |
| Endomina · POSE · Overstitch, 5 años | 499 / 699 € | **599 / 799** € |
| Balón gástrico, 1 año | 169 / 249 € | 169 / 249 € |
| Balón gástrico, 2 años | 199 / 279 € | **219 / 299** € |
| Balón gástrico, 5 años | 249 / 299 € | **269 / 329** € |

El formulario rellenable calcula con los precios impresos en el propio formulario.
